# Coast & Keys

Apartment finding in Da Nang. Full service until you find your new home.

**Live site:** https://USERNAME.github.io/coastandkeys/

## What this is

The website for Coast & Keys, a service that finds apartments in Da Nang, Vietnam, within your budget. We search, visit, negotiate, and check the contract. You move in.

It is a single static page: plain HTML, CSS, and JavaScript. There is no build step and no database.

## Update the site

1. Open `index.html` in this repository.
2. Tap the pencil icon (Edit).
3. Make your change and tap **Commit changes**.
4. Wait 1 to 2 minutes. GitHub Pages updates the live site.
